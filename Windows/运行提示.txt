MCChat Windows 运行提示
========================

一、准备
  1. 需要装有 Python 3.8+（官网 python.org 安装时勾选 "Add Python to PATH"）。
     没有 cryptography 库也没关系：run.bat 检测到后会自动 pip 安装。
  2. 两台电脑用网线直连（或同一局域网 / 同一手机热点）。
  3. 本目录下的 mcchat.py 与 Ubuntu/ 里的完全相同，跨平台、无需修改。

二、启动
  1. 双击 run.bat。
  2. 按提示输入节点名（如 Alice / citrine），直接回车默认用计算机名。
  3. 输入本机直连网卡的 IPv4 地址（必须填，不能留空）：
     - 查看方法：Win+R → cmd → ipconfig → “以太网适配器”下的 IPv4 地址；
     - 网线直连、没有路由器时通常是 169.254.x.x（自动专用地址 APIPA）；
     - 程序的自动探测走默认路由，电脑上有 VMware / Wi-Fi 等多块网卡时
       会选错出口，所以直连时必须手动指定。
  4. 首次运行若弹出 Windows 防火墙提示，勾选“专用网络”并点“允许访问”，
     否则对方收不到多播报文和单播密钥。

三、常用命令（在程序窗口里直接输入）
  /members                当前成员列表（HELLO 视图）
  直接输入文字             发送多播文本，所有在组成员都能收到
  /file 路径              发送文件，例如：
                            /file ..\测试媒体\sample.mp4
                            /file D:\videos\demo.mp4
  /kick 名字              踢出成员（= 密钥轮换；被踢者仍能收包但只能看到密文）
  /leave                  退出多播组：不再接收，但密钥有效期内仍能发送
  /join                   重新加入（HELLO/JOIN_REQ/KEY_GRANT 重新握手）
  /keyinfo                查看当前 epoch、密钥指纹、剩余有效期
  /quit                   退出程序

四、收到的文件
  保存在本目录 downloads\<节点名>\ 下。Windows 不会自动弹出播放器
  （自动播放用的 xdg-open 是 Linux 命令），收完后到该目录手动双击播放。
  参考数据：sample.mp4（648,721 字节 / 634 块）直连实测发送 1.012 s、
  接收 0.983 s、端到端 1.282 s。

五、退出后仍能发送的原理
  程序里发送 socket 从不 join 多播组，只有接收 socket 会
  IP_ADD_MEMBERSHIP；/leave 只关闭接收 socket，所以退出后仍能发，
  但收不到别人发的消息。发送用的组密钥有有效期（默认 120 s），
  超过有效期再发会提示 key expired，需要重新 /join 取新密钥。

六、自动化测试（可选）
  在本目录执行：python test_driver.py
  会自动启动 3 个本地实例，跑 33 项断言（加入/发现/文本/文件/踢人/
  退出/重加入/密钥轮换），测试音频由脚本自动生成，全部 PASS。
